# befrosh_fast_woocamers-sall

مخزن توسعه‌ی افزونه‌ی **Fast Woo Sell** (`fast-woo-sell`) — افزونه‌ی ووکامرس برای
پیشنهاد هوشمند محصول، پیگیری سبد رها شده و پیش‌بینی موجودی.

## وضعیت فعلی

| مستند | توضیح |
|---|---|
| [`docs/بررسی-کد-و-نقشه-راه.md`](docs/بررسی-کد-و-نقشه-راه.md) | بررسی کامل کد، فهرست کمبودها و نقشه راه |

خلاصه: موتور ردیابی و موتور پیشنهاد نوشته شده‌اند، اما پنل مدیریت و نمایش
پیشنهادها در فروشگاه هنوز ساخته نشده‌اند.

## توسعه

### بررسی سینتکس PHP بدون نصب PHP

اگر روی ماشین شما PHP نصب نیست، می‌توانید همان بررسی‌ای که CI انجام می‌دهد را
اجرا کنید:

```bash
npm install
npm run lint:php
```

این اسکریپت:

- هر فایل PHP افزونه را با یک پارسر مستقل می‌خواند و خطاهای سینتکس را گزارش می‌کند
- فایل‌های پیش از «دروازه‌ی نسخه» (`fast-woo-sell.php` و
  `includes/Core/Requirements.php`) را برای سینتکس ممنوعه‌ی PHP 5.6 بررسی می‌کند

> محدودیت: این ابزار جای `composer lint` را نمی‌گیرد. بررسی سازگاری نسخه‌ای
> (۷.۴ برای باقی فایل‌ها) کار WPCS و PHPCompatibilityWP است و به PHP نیاز دارد.

### با PHP نصب‌شده

```bash
cd fast-woo-sell
composer install
composer check     # phpcs + سازگاری نسخه‌ها + phpunit
composer fix       # رفع خودکار خطاهای استاندارد کدنویسی
```

### ساخت بسته‌ی نصب

بسته‌ی ZIP آماده‌ی نصب باید فقط پوشه‌ی `fast-woo-sell` را در ریشه داشته باشد:

```bash
cd fast-woo-sell && zip -r ../fast-woo-sell.zip . -x 'tests/*' 'composer.*' 'phpcs*' 'phpunit*'
```

## نصب برای تست

1. فایل ZIP را از مسیر **افزونه‌ها ← افزودن ← بارگذاری افزونه** نصب کنید
2. ووکامرس را فعال و چند محصول و چند سفارش آزمایشی ایجاد کنید
3. صفحه‌ی یک محصول را باز کنید تا ردیابی شروع شود
